# HGSIM.DLL 1.0 vs 1.2: the changed functions

Generated by the round-30 analysis scripts (scratchpad), read-only. 1.0 = GameRip/HGSIM.DLL (1997-11-18), 1.2 = GameRip_12/hgsim.dll (1998-07-23). Functions are matched on their instructions with every address normalised; function starts come from call targets and prologues, so a few pairs are cut at the wrong place (noted where seen). "d" = instructions added + removed, "r" = similarity 0..1.

## Counts

- 2865 functions in 1.0, 3017 in 1.2; 1963 identical apart from addresses.
- 553 paired but changed: 324 with only record-field offsets changed (layout), 25 with operand-form changes, 204 with real logic changes.
- 345 functions of 1.0 without a clear partner, 670 functions of 1.2 new or without a partner.

## Layout change

All "numbers" functions differ only in record-field offsets, nearly all shifted down by 4 ([reg+0x1c] -> 0x18, 0x28 -> 0x24, 0x54 -> 0x50, 0x1aa -> 0x1a6, 0x218 -> 0x214, ...): 1.2 removed one dword at +0x18 of the object record (0x109e8b40 table). Code carried over from 1.2 must have its offsets mapped back to 1.0 (+4 above 0x18).
