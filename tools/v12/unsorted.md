# Unsorted 1.2 functions: verdicts (round 33 follow-up)

Read-only analysis. Input: the survey's "Unclassified" rows (69 changed, 102 new) and "No converted 1.0 twin found" rows (69 changed, 21 new) of `tools/v12/survey.md` / `survey.json`, 261 functions. Nothing here is ported.

## Method

- Changed functions: `tools/v12/fdiff.py`, then again with a wider layout filter that also accepts immediates 4 lower (`add reg, 0x19c` -> `0x198`, the record shift written as arithmetic) and the stack frame size. "d now" in the size column is that recount; 21 rows drop to 0. Rows still showing differences were read side by side.
- New functions: 1.2 disassembly with its callers, callees, strings and globals mapped to 1.0 (`globalmap.json`, `funcmap.json`, the survey pairs, our C) and the DLL import names.
- "Inside": many rows are not function starts but addresses in the middle of a 1.0 / 1.2 function (the survey's start finder takes every call target and some misaligned decodes). For those the verdict is "already converted under another start address" and the change belongs to the containing function. Checked against Ghidra's function list (1.0) and the nearest 1.2 prologue.
- "Already ported" is from the working tree as of 2026-10-31: some functions the survey lists as unported have been done since (footstep dust, force feedback, w9d_select, part of w16_move).
- Survey caveat confirmed: its area labels came from keywords in our C and are often wrong for these rows; the areas below are by what the code does.

## Notable 1.2 features found here

1. **WAV music instead of CD audio** (about 35 functions): `wavmap.ini` ([WAVMap] Track1..n, DVDDrive, DVDMoviePath) maps the CD tracks to WAV files, which a new DirectSound streaming player plays with a winmm refill timer; the CD-music calls go through a pointer that picks CD or WAV. Optional for us (the shell side is already handled in hooks_cd.c, DECISIONS.md round 33).
2. **zlib** (about 35 functions): a full inflate decompressor plus a "ZLIB"-tagged block reader. A library; data files packed with it need it (Project archives already use zlib, docs/formats/prj.md). Our C can use a stock zlib.
3. **A gear action gate** (1.2 0x10010cd2 and four flag tests): new unit flags +0x560 / +0x562 ("jets cut" and others) can stop a locally driven gear acting in a tick. Belongs with the movement round.
4. **Network game end and resurrection**: a "game is ending" flag makes about twenty network message handlers ignore traffic (a dozen of them in this list); new messages for unit state, resurrection ("Out of regenerations: Press SPACEBAR...") and game settings.
5. **HGCAR.CFG grew** from 0x1d4 to 0x21c bytes: a 1.2 file written by 1.0 code (or the reverse) does not match; port with the mission flow.
6. **Weapon slots**: a new 8-slot weapon bookkeeping (0x1002cdc5, gear field +0x5fb).
7. **Missile launch effects** (smoke / flame particles) inside the 1.0 missile launch: the particle port's missing caller.
8. **Render**: polygon submit with 1/w per vertex and renumbered driver states; a wider animated-texture frame table with a new texture loader; PowerVR-only state toggles (dead for us).
9. **More sounds and texts**: one more sound bank (index 3), about 46 more squad radio / status text lines.
